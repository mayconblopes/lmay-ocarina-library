# First exercises on the ocarina

After learning some notes and developing a comfortable posture, we can begin practicing small exercises.

## Exercise 1 — consecutive notes

Start by playing a simple sequence.

The goal is to produce each note clearly.

## Practice slowly

It is not necessary to start quickly.

A slow and consistent execution is much more useful for developing coordination.

## Next step

After mastering simple exercises, we can begin working on complete scales.
